# IITM Quizzes Repository

Welcome to the IITM Quizzes repository. This project is designed to manage and explore quizzes, providing a structured format for quiz data.

## Project Structure

The repository is organized as follows:

- **backend/**: Contains the server-side code responsible for handling quiz data operations.
- **quiziverse-explore/**: Includes the frontend components for quiz interaction and exploration.
- **.gitignore**: Specifies files and directories to be ignored by Git.
- **readme.md**: The current document providing an overview of the project.

## Technologies Used

- **TypeScript**: Utilized for both backend and frontend development, ensuring type safety and scalability.
- **Python**: Employed for specific scripting tasks within the project.
- **CSS**: Applied for styling the frontend components.
